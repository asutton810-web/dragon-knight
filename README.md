# iHODL810: Dragon Knight

A browser action game by iHODL810. Fight waves of dragons and the Obsidian Tyrant boss as the Dragon Knight.

Play: https://asutton810-web.github.io/dragon-knight/

Controls — Phone: ◀ ▶ move, JUMP, ⚔ slash, hold 🛡 to block. Keyboard: A/D or arrows move, W/Space jump, J slash, K/Shift block, M mute.

All game code and art are in the single `index.html` file.
